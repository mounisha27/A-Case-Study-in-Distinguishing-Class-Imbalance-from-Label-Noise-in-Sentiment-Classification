About the Project
This is an extension of my MSc thesis, “Customer Segmentation based on Sentiment Analysis”. I implemented and tested three Machine Learning models -- Support Vector Machine (SVM), Decision Tree (DT), and Neural Network (NN). All three models showed unusually high accuracy, which made me suspicious. I started looking at the recall. There it was 0% recall for the “negative” class with 90% accuracy for SVM, while the NN could identify only 14% of the negative class with 88% accuracy. I then started looking into the minority class problem in Machine Learning and tested different sampling techniques: Random Oversampling (ROS), Random Under-sampling (RUS), SMOTE (Synthetic Minority Oversampling Technique), Borderline-SMOTE, and ADASYN. None of them gave me an F1-score that I considered satisfactory. Some techniques, such as RUS, improved minority-class recall, but at the same time affected the majority class significantly. This made me look further into the code and, more importantly, into the data itself. Since there were only 7 negative examples in the test set, I manually checked the data and found that my sentiment-labelling logic was not properly representing the classes. I changed the data-labelling algorithm and repeated the experiments with the different sampling techniques. The results showed a significant improvement in minority-class detection.

This is an independent research project aimed at understanding how data-level and algorithm-level interventions can improve the detection and overall performance of Machine Learning models on rare and hard-to-detect minority classes.
